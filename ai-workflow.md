# AI-Native Workflow Note

As an AI-forward developer, I utilized AI (LLM chat) as a pair programmer to accelerate delivery:

- **Where it sped up work:** Boilerplate generation (setting up TipTap extensions, Tailwind layouts) and writing the regex/logic for the Jest test setup. It saved ~45 minutes of reading documentation.
- **What I rejected/changed:** The AI initially suggested building a full document deletion feature and adding heavy libraries for file parsing. I actively rejected these to enforce strict timeboxing and scope management (Product Judgment).
- **Verification:** I manually tested the UI rendering (fixing Tailwind CSS reset conflicts on lists/headings) and verified business logic by writing a Jest automated test for the file validation logic.
